# 飞书命令入口验收说明

## 关联模块

飞书机器人私聊/群聊的派单引导, 员工列表与模型查询, 员工默认模型切换, 员工新建会话, MCP 关联身份凭证的派发认证.

## 配置说明

无新增数据库迁移或必填配置. 模型目录沿用员工关联工作站上报的数据. 修改模型/新建会话要求飞书发送者事先绑定目标员工. MCP 认证沿用员工关联身份凭证中配置的认证方式和注入设置.

## 配套工具说明

使用说明见 [FEISHU_COMMANDS.md](FEISHU_COMMANDS.md). 自动测试使用模拟消息、内存服务和本机模拟 SDK 服务, 不发送真实飞书消息. 真实机器人需部署后验收私聊和群聊收发.

工作区原有任务用量统计、工作站 Provider 适配、身份凭证表单等未提交改动不纳入本次修改清单. 本次对已有 MCP 认证链路补充关联凭证变更后的派发回归测试.

## 测试要点

1. 私聊发送普通文字时显示派单示例和命令说明; 图片和文件先暂存并提示后续派单方式. 群聊普通闲聊不回复; 未知命令、显式提及但不支持的格式显示提示. 只 @员工 未提供任务需求时不创建任务. 附件链路的补充验收见 FEISHU_ATTACHMENTS.md.
2. `/help` 与错误格式提示均展示已实现的命令. `/helpful`、`@员工 /models-typo` 不被误匹配, 不创建任务. `/emp 员工 /status` 可查询状态.
3. `/list emp` 显示已登记员工及在线/可派单状态. `/model` 与 `/model 员工` 按员工关联工作站查询, 支持空模型目录、无绑定、员工不存在时的明确提示. `/status` 区分默认配置与已运行任务.
4. `/change model` 和 `/change mode` 均支持员工别名、@别名、员工 ID. 模型 ID 或含空格的完整模型名称可用; 不存在的模型不修改配置. 未绑定发送者不能修改模型或新建会话, 控制命令不得自动建立身份绑定.
5. `/new 员工`、原有中文新建会话与模型切换命令继续工作. 新会话仅影响后续任务. 同一事件重复投递只执行一次.
6. 使用系统实际生成的含小写字符员工 ID 查询和派单正常. 原有 @别名、/emp、员工 ID 派单不回归.
7. 同一关联凭证依次修改为 Basic、Token、Bearer 和自定义 API Key 请求头后, 下一次任务派发随该凭证配置变化. 不因 MCP 名称或旧认证类型继续固定发送 Basic.

## 修改清单

1. 飞书命令注册、别名匹配、自动帮助生成和参数校验.
2. 员工状态与工作站模型目录查询适配和启动接线.
3. 控制命令提前处理, 复用原有身份校验、模型校验、配置保存和审计.
4. 飞书文本/富文本解析与消息类型传递, 不支持格式与空任务提示.
5. 员工 ID 大小写保留, 模型命令匹配边界收紧.
6. 命令与关联凭证认证回归测试, 使用和扩展说明.
