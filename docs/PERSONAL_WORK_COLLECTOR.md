# 内置个人工作采集器

`personal-work-collector` 运行在 Control Plane Go 进程内，端点为 `POST /mcp/collector`。它与 `workflow-mcp` 共用 MCP 协议处理、凭证签发、吊销、用户状态检查和外部写权限管理；无需启动原 Python 服务。

后台入口：**工作采集中心**（`/mcp-servers/personal-work-collector`）。个人凭证也可在 **个人设置 → 我的工作账号** 管理。

## 首次使用

1. 部署代码并执行项目正常数据库升级流程，包含 `000037_mcp_external_user_policies.sql` 和 `000038_work_collector.sql`。升级前按既有部署流程备份数据库。开发模式未连接数据库时使用内存存储，重启会清空采集配置和授权状态。
2. 配置 `AIE_PUBLIC_SERVER_URL` 为浏览器访问平台的公共地址。后台显示完整 OAuth 回调地址：`<平台地址>/api/collector/oauth/callback`。飞书应用需登记该重定向 URL。OAuth 回调必须与发起授权的网页共用 Cookie 域名；独立的 `AIE_MCP_PUBLIC_URL` 只用于 MCP 连接。
3. 用户打开「我的工作账号」，设置姓名、别名、时区。飞书 App ID 留空时使用管理员启用的平台飞书应用进行**个人 OAuth 授权**；也可以填写本人管理的 App ID / App Secret。
4. 勾选需要的飞书能力，保存并点击「连接我的飞书账号」。应用需已开通对应权限，用户在飞书授权页同意访问。需要自动续期时申请 `offline_access`。高级设置可直接编辑空格分隔的 Scope。
5. 新建扫描目标，读取资源结构，配置工作表或目录及字段映射，先预览，再保存启用。默认首次扫描只建立基线。需要通知时，另在个人设置启用通知、配置通知群或群机器人，并创建通知规则。
6. 在「个人设置 → 外部 MCP 授权」选择工作流、工作采集器或两者，生成客户端 JSON / TOML 配置。两个服务独立选择 READ / WRITE。WRITE 需管理员事先在该用户的授权面板授予相应服务写权限。

飞书应用身份和用户身份不同。平台应用只作为个人 OAuth 的客户端；`identity=app` 必须显式指定，并且需要用户配置本人管理的应用。用户授权过期、权限不足或资源不可见时，调用报错，不切换到平台机器人。

## 个人身份与凭证

- 飞书 OAuth state 绑定平台用户与浏览器 HttpOnly Cookie，十分钟有效、一次性使用，并附带 PKCE。回调换取用户凭证后，调用用户信息接口验证 `open_id`。
- 每人独立存储 App Secret、用户 Access/Refresh Token、Jira Token、飞书项目插件凭证和通知 Webhook，使用现有 SecretManager 加密保管。REST/MCP 状态接口只返回配置状态、身份和有效期，不返回密钥。
- 用户 Token 接近过期时自动续期，续期过程按用户加锁。新授权不会继承旧 Refresh Token；换应用、断开授权或重新授权都会使旧的写操作确认失效。
- 允许导入现有 `user_access_token`，必须提供有效期，并通过用户信息接口校验。手动导入的 Scope 无法通过该接口验证，因此界面显示「范围待验证」。
- 界面分别展示申请的 Scope 与飞书实际返回的 Scope。显示「范围已授权」不代表任意资源可读写，实际资源权限仍由飞书校验。
- Jira 支持 PAT 和账号 + API Token。飞书项目支持个人 Plugin ID / Secret 自动获取及续期 Plugin Token，也可导入已有 Plugin Token；手动 Token 过期后需更新。
- 断开个人授权会移除平台保存的用户凭证。若需要撤销飞书侧的授权，请同时在飞书授权管理中撤销。

## 授权模型

| 调用者 | 数据身份 | 权限 |
|---|---|---|
| 平台普通用户访问采集后台 | 当前登录用户 | 管理本人的配置、个人凭证、预览及扫描 |
| 后台管理员管理其他用户 | 显式选择目标用户 | 需全局用户管理权限及工作流读/写权限；无权查看或修改对方密钥 |
| 员工绑定内置采集器 | 每次请求解析当前员工所有者 | READ；按绑定的 AllowedTools / DeniedTools 过滤 |
| 外部 READ Token | Token 所属平台用户 | 读取本人采集数据和本人有权访问的飞书资源 |
| 外部 WRITE Token | Token 所属平台用户 | 当前服务写授权仍有效时可预览、确认执行；不包含删除 |
| 受支持的管理会话 | 当前平台用户 | 沿用工作流 RBAC，删除另需 `workflow.delete` |

Token 的 `service` 只允许一个内置服务。工作流 Token 不能调用采集器，采集器 Token 不能调用工作流。旧 Token 的默认 audience 为 `workflow-mcp`。后台管理员身份不隐含外部 MCP 写权限。收回某服务写权限立即影响后续调用，不影响另一服务；禁用用户、吊销凭证、停用 MCP 服务或移除员工绑定都会影响对应 MCP 请求。

MCP 停用控制 MCP 接口可用性；采集任务自身由目标的启用开关控制。需要停止自动采集时应暂停目标。

## 后台设计与扫描来源

六个页签：**概览、扫描目标、规则与通知、工作事项、运行记录、接入与身份**。编辑目标使用左侧配置、右侧预览布局。

| 来源 | 可配置内容 | 采集行为 |
|---|---|---|
| Jira | 个人站点/账号、JQL、是否仅本人、全量或增量、完成状态 | 分页读取；增量附加更新时间与重叠窗口。增量 JQL 需覆盖已完成事项，否则应选全量扫描 |
| 电子表格 | URL/Wiki URL、工作表选择/自动发现、读取区域、表头行、唯一标识/标题/人员/状态/截止日期列 | 行级快照比较；行排序不应触发变化。配置稳定的唯一标识列，重复标识会明确报错 |
| Wiki | 文档或目录 URL、递归、深度、节点上限、标题正则、画板选项 | 监控 doc/docx 正文，可选监控内嵌画板；搜索专用目录只在 MCP 搜索时读取 |
| 多维表格 | Base/Wiki URL、Table、View、人员及状态日期字段、筛选 JSON | 分页读取，按 record_id 比较 |
| 飞书项目 | 项目 Key、个人 User Key、插件凭证、首次回溯天数 | 分页增量对账，默认回溯 90 天，后续保留十分钟重叠 |
| 飞书消息 | Chat ID、是否仅 @ 本人、首次回溯天数 | 默认回溯七天；按水位分页读取，后续保留十分钟重叠；平台收到相关群消息事件时唤醒扫描 |

飞书消息使用当前用户可访问的群范围；事件通知只是重新读取资源的提示，不把未经授权的事件载荷直接写入个人工作记录。消息轮询按创建时间取水位，较早消息的后续编辑不保证通过轮询补获。

各目标可选择扫描间隔或五段 Cron、时区、首次扫描是否通知、启用状态。默认 `A1:AZ1000` 是明确的表格读取范围，需要更多行时在后台调整。表格无唯一标识时以标题/人员生成后备标识，标题或负责人改变可能表现为旧项移除、新项创建；正式任务表推荐设置唯一标识列。

人员筛选使用当前用户的姓名、别名、飞书身份或 Jira/项目账号，具体匹配字段由来源配置控制。工作事项页汇总本人配置范围内的快照；目标设置为读取全部人员时，结果也会包含该目标范围内的其他人员事项。

## 规则、预览、调度与通知

- 规则按优先级从小到大匹配第一条；同优先级按规则 ID 排序。支持全部/任一条件，以及等于、不等于、包含、属于列表、发生变化、是我、N 天内到期、有值。
- 通用字段有 `source`、`event_kind`、`title`、`status`、`assignee`、`due_date`；也可引用源数据字段，例如表格的「验收人」。状态变化规则同时支持通用 `status` 和原始「状态」字段。
- 规则针对本轮产生的变化事件执行；仅时间推移、数据未变时不会额外产生到期事件。未命中规则仅记录。
- `record` 仅记录，`instant` 生成即时通知，`batched` 按规则和固定时间窗口合并多目标、多轮扫描的事件。个人通知开关关闭时不新建投递任务，已待发任务暂停投递。
- 预览读取真实上游数据并计算差异/规则，但不写正式快照、事件或通知；访问凭证续期与密钥访问审计仍可能发生。REST 预览超时九十秒，范围较大时缩小范围后重试。
- 手动扫描持久化排队并立即返回 HTTP 202；后台约二十秒检查一次，最多四路并发。运行页显示 queued/running/success/failed，排队或运行期间网页自动刷新。
- 正式扫描最多四分钟，单目标租约六分钟。快照、事件、投递队列及下次调度时间一起提交；上游失败保留上一份成功快照。保存/删除目标与扫描使用同一租约，冲突时提示稍后重试。
- 通知由独立投递队列重试，最多八次，失败后可在后台重试。飞书 IM 投递带稳定 UUID；群机器人 Webhook 在发送后服务崩溃等情况下可能重复，不承诺跨网络故障严格只投递一次。
- 事件、运行记录、工具调用记录及已完成通知保留九十天；OAuth/操作确认过期记录和租约定期清理。失败或未完成通知保留以便处理。管理页最多显示最近五百条记录。
- 飞书/Wiki/消息/多维表格读取设置了分页和总量上限；超限明确报错，不用截断结果覆盖旧快照。

签名事件入口：`POST /api/collector/webhooks/{owner}/{target}`。先在个人设置配置 HMAC 密钥，再用请求原文计算 HMAC-SHA256，放入 `X-Hub-Signature: sha256=<hex>`。重复载荷二十四小时内去重；目标必须启用。

## MCP 工具与本地飞书技能的关系

保留原采集器的 **47 个工具名称**，另加 **6 个工具**：

| 新工具 | 能力 |
|---|---|
| `search_feishu_documents` | 以用户身份检索云文档/Wiki，返回分页游标 |
| `list_feishu_drive_files` | 列出云空间目录 |
| `read_feishu_docx` | 通过 docx/Wiki URL 读取正文 |
| `create_feishu_docx` | 创建文档 |
| `update_feishu_docx_block` | 修改指定文档块 |
| `list_feishu_calendar_events` | 读取指定日历或本人主日历的日程 |

原工具涵盖工作量/到期事项/简报、Wiki 目录与内容检索、电子表格、人员搜索、消息/卡片/图片/文件、忙闲/日程、任务、文档追加/评论、表格写入/样式/合并/工作表管理、知识库节点、多维表格记录、原生审批和视频会议预约。

常见的「查找 → 阅读 → 修改/创建」流程已经接入。它不是把本机全部 `lark-*` 技能和 CLI 原样搬到服务器：白板仅支持已实现的读取链路，其他如云盘批量管理、电子表格高级图表、邮件、考勤、OKR 等并未提供完整工具族。上游 API 的身份支持、租户应用权限和资源 ACL 决定某项操作是否可用。

兼容性差异：

- `search_feishu_wiki` 保留原来的 `question` 参数；检索本人 Wiki 快照、搜索专用目录及显式 `root_url`，不是全租户语义索引。
- READ 工具 `refresh=true` 进行实时读取，不再隐式改写扫描基线或触发通知；请通过后台正式扫描更新采集快照。
- 部分结果统一为 Go 版的 `items` / `rows` / `targets` 结构，并非原 Python 响应 JSON 的逐字段兼容。
- 文件/图片发送使用 `file_base64` 和纯文件名 `file_name`，最大 5 MiB，不接受读取服务器本地路径。
- 原生审批需显式 `identity=app`，只允许为已验证的本人 `open_id` 发起，不能代任意用户提交。
- 视频会议工具创建有效期截至 `end_timestamp` 的会议预约；`start_timestamp` 保留为预览意图，不会创建日历日程。安排开始时间请使用日程工具。
- 外部 WRITE 不包括删除工作表；删除需要独立权限。
- 日期以个人时区处理；`list_due_soon` 未指定天数或传负数时默认七天。审计查询即使 `only_me=false` 也只返回本人记录。

所有 MCP 写工具先返回 `confirmation_required`，其中包含完整预览、五分钟有效的 `confirm_token`。客户端展示预览并取得用户确认后，再调用同一工具并携带 Token。确认绑定用户、客户端凭证、工具、操作参数和飞书授权；参数或身份改变后须重新预览，确认令牌只能消费一次。应用本身不替客户端判断用户是否看过预览。

## 从旧采集器迁移

在扫描目标页「导入原采集器配置」粘贴 YAML，先检查映射结果再确认导入：

- `sheets.yaml`：拆分为扫描目标，带工作表和字段设置，停用保存。
- `wiki.yaml`：`documents` 为监控目标，`knowledge_roots` 为搜索专用目录，均不会自动发通知。
- `rules.yaml`：支持能够转换的条件，以停用规则保存。包含 `projects`、`or_mentioned`、原始事件类型等不能无损映射的条件时拒绝导入并指出字段，请在后台重建，不静默丢弃条件。
- `people.yaml`：一次只导入一个人员条目到当前登录用户，可导入姓名、别名、Jira/项目账号及旧 Jira/机器人凭证；不会自动创建账号，也不会导入旧 MCP Token。飞书个人 OAuth 必须重新连接。

导入不会迁移旧 `.env`、SQLite 历史事件或旧 MCP 凭证；原项目可保留作历史查询，新系统通过首次扫描建立基线。配置导入应只操作实际要迁移的本人条目，含密钥的内容不会在导入预览中回显。
