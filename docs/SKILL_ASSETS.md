# Skill 资产管理

入口: MCP 服务管理 / workflow-mcp / 技能包 / 编辑.

## 行为

- 文件树列出主文件及所有附属文件, 包含隐藏文件和原目录层级. 内容按选中的文件读取.
- UTF-8 文本在浏览器中编辑, 保留 BOM 和原换行格式. 支持修改前后差异对比.
- 图片支持预览. 二进制, 非 UTF-8 或超过 1 MiB 的文件可下载和上传替换.
- 支持新建文件, 批量上传, 目录上传, 选中嵌套路径文件后直接替换, 标记删除及逐项撤销.
- 修改后恢复原内容不算变更. 新建后删除抵消操作. 清空文件保存为零字节文件.
- 保存只上传发生变化的文件及明确的删除路径. 服务端再按内容过滤无变化的操作, 仅写入变化文件.
- 同一批变更在事务中完成. 失败保留草稿, 不会部分保存. 无变化不写库, 不增加修订号.
- SKILL.md 不可单独删除, 其 id 不可修改. 支持保留自定义 front matter, 注释和原文格式.
- 仅修改附属文件不自动修改 SKILL.md 的版本号. 内容哈希负责识别资产变化.
- 离开页面或重新加载前提示未保存内容. 草稿在当前页面内保留, 不跨刷新持久化.

## 接口

- GET `/api/workflow-mcp/skills/{id}/files`: 返回 skill 元数据和文件索引, 不下载附属文件内容.
- GET `/api/workflow-mcp/skills/{id}/file?path=...`: 返回单文件原始字节, `X-Skill-Revision` 为读取时修订号. 文件响应禁止缓存.
- PATCH `/api/workflow-mcp/skills/{id}/assets`: multipart 请求, manifest 字段含 revision, writes 和 deletes. writes 的每项含 path 和 part, part 指向对应的上传文件字段.
- 保存响应返回本次提交的修订号, 内容哈希, skill 元数据和提交文件的新索引. 不把另一个并发写入的结果混入响应.

约束: 单文件最多 16 MiB, 单批内容最多 64 MiB, HTTP 请求最多 66 MiB, 单批最多 1024 个操作. 路径必须为规范相对路径, 不允许路径穿越, 文件与目录冲突, 仅大小写不同的重复路径和 Windows 保留名称.

## 并发与权限

每次保存携带打开页面时的包修订号. 数据库对包记录执行原子比较并递增, 文件增删改在同一事务中提交. ZIP 导入和 MCP/旧 REST 写入也更新修订号, 旧接口未传 files 时保留资产, 显式 files 数组仍表示完整附属文件集合.

修订不匹配返回 409. 界面保留草稿并展示服务端变更路径. 不重叠操作可合并到最新基线; 同一文件冲突需要明确选择保留本地操作或采用服务端, 文本可比较最新内容. 合并后需要再次保存, 不自动覆盖远端.

查看沿用 workflow.read. 写入要求 workflow.write 的 ALL 范围, 删除同时要求 workflow.delete 的 ALL 范围. 只读用户可浏览和下载.

MCP `check_skill` 支持 local_content_hash, `check_local_skills` 的每个本地技能支持 content_hash, `check_workflow_skills` 支持 local_content_hashes 映射. 提供哈希时优先对比内容; 旧调用方只提供版本号时保留旧行为. 工作站原有 content_hash 同步机制继续生效.

## QA 摘要

### 历史目录标记兼容修复

已在实际数据中确认 code-merge-tools 包包含 scripts/ 的零字节目录标记. 旧 ZIP 导入会把目录项存为附属文件, 增量保存校验整个集合时将其作为非法文件拒绝, 导致仅编辑 SKILL.md 也无法保存.

对规范相对目录路径且内容为空的历史标记做兼容: 文件索引和导出不再把目录标记当成文件, 保存时忽略这些旧标记并保留其存储记录, 内容哈希仅计算实际文件. 新增/修改请求仍严格校验路径, 非空目录路径及不安全路径仍拒绝. 真实零字节文件继续作为文件保留.

回归覆盖历史标记存在时修改主文件和脚本, 仅主文件更新时附属资产无写入/删除, 索引和导出过滤目录, 普通空文件保留, 旧接口省略 files 可保存以及非法路径仍被拒绝.

